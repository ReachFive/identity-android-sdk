== Register a new device

Registration is a _two-step process_.

TIP: Each tab below shows the code needed for each step.

. The xref:addNewWebAuthnDevice.adoc[] method initiates the FIDO2 registration process to retrieve a randomly generated challenge, the *Relying Party* information, and the user information from the {company} server. The options are then passed to the FIDO2 API which returns an *Android Intent* to open a fingerprint dialog and generates a new credential.
+
WARNING: A user cannot register several credentials on the same device.
+

[start=2]
. The xref:onAddNewWebAuthnDeviceResult.adoc[] method is called after the UI successfully generates a new credential. It sends the resulting data (_which contains the information about this new credential_) back to the {company} server and completes the FIDO2 registration process.
