= Signup

The user requests to register a new account for the first time.
Users don't need to provide a password, but instead provide an identifier like an email or mobile number as well as some personal data and a xref:signupWithPasskey.adoc[`friendlyName`].
The data they provide in the signup process is reflected in the `profile` option in the `signupWithPasskey` method.
