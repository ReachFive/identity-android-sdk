= updatePhoneNumber


[.signature]
[subs="normal"]
----
client.updatePhoneNumber(
    <<freshAuthToken-{docname}, authToken>>,
    <<phoneNumber>>,
    <<successwithupdate, success>>,
    <<failure>>
)
----

== About this command

Update the profile phone number and send a verification code by SMS.

[NOTE]
====
* Your access token must have the `full_write` scope.
* Be sure to configure and to enable the _Verification SMS_ template in the account's settings.
====
