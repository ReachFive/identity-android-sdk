== About this command

Initiates the step up process needed for the MFA flow and starts the passwordless flow by sending an email or SMS to the user with a single-use auth code or access token (depending on the response type).

You can initiate the step up with an `authToken` or with with the `tkn` received from xref:sdk-android:ROOT:loginWithPassword.adoc[].

IMPORTANT: The Passwordless feature must be enabled on your {cc} account.
The SMS feature must be enabled on your {cc} account if the profile can choose a phone number to login.
