[.signature]

client.onAddNewWebAuthnDeviceResult(
    <<requestcode, requestCode>>,
    <<fido2intent, intent>>,
    <<success>>,
    <<failure>>
)
----

== About this command

After launching a FIDO2 registration task (with the xref:addNewWebAuthnDevice.adoc[] method), this method will parse the resulting intent and if successful, the new device will be added in the user's registered FIDO2 devices.

[NOTE]
====
* The WebAuthn feature must be enabled on your {company} account.
====
