= requestPasswordReset


[.signature]
[subs="normal"]
----
client.requestPasswordReset(
  <<email>>,
  <<phoneNumber>>
  <<success>>,
  <<failure>>
  // Optional arguments
  <<redirectUrl>>,
  <<origin>>
)
----

== About this command

Request a password reset for a profile. It will send an email if the email address is provided and an SMS if the phone number is given.

Be sure to configure and to enable the _Password reset email_ or the _Password reset SMS_ templates
in the account's settings.
