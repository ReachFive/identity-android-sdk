== About this command

When authenticated, the user can add a new FIDO2 device. This method will get a FIDO2 pending intent for registration with the options returned by the {company} server and launch it.

The result will be processed by the xref:onAddNewWebAuthnDeviceResult.adoc[] method.

[NOTE]
====
* The WebAuthn feature must be enabled on your {company} account.
====
