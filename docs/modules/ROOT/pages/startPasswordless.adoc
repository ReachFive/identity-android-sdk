= startPasswordless


[.signature]
[subs="normal"]
----
client.startPasswordless(
  <<email>>,
  <<phoneNumber>>
  <<success>>,
  <<failure>>,
  <<activity>>,
  // Optional arguments
  <<redirectUri>>,
  <<captcha>>
)
----

== About this command

Starts a passwordless flow by sending an email or an SMS to the profile with a single-use auth code.
