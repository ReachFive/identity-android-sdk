= exchangeCodeForToken


[.signature]
[subs="normal"]
----
client.exchangeCodeForToken(<<authorizationCode>>, <<success>>, <<failure>>)
----

== About this command

Exchange an authorization code for an access token.

WARNING: This method is set to be deprecated. All SDK flows should be fully handled by the client. If you are using this method for a custom implementation, please contact your account's support representative so that we may assist you accordingly.
