== About this command

Logs in a user by initiating the authentication code flow, ending the step up flow.
This is executed when a user uses the SMS verification code or clicks the link provided in the email.

IMPORTANT: The Passwordless feature must be enabled on your {cc} account.
The SMS feature must be enabled on your {cc} account if the profile can choose a phone number to login.
