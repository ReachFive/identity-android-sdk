= requestAccountRecovery

[.signature]
[subs="normal"]
----
client.requestAccountRecovery(
  <<email>>,
  <<phoneNumber>>,
  <<success>>,
  <<failure>>,
  // Optional arguments
  <<redirectUrl>>,
  <<captcha>>
)
----

== About this command

Request account recovery for a profile.
The profile receives an email if you pass an email address, or an SMS if you pass a phone number.

You must configure and enable the xref:docs:ROOT:email-templates.adoc#account-recovery[Email Account Recovery] and/or the xref:docs:ROOT:sms-templates.adoc#account-recovery[SMS Account Recovery] templates in your {company} account settings.

When the {cc} protects forgot password with a `Captcha`, pass <<captcha,`captcha`>>.
This method uses the same `Captcha` configuration as xref:requestPasswordReset.adoc[].
