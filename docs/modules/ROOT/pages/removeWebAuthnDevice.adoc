= removeWebAuthnDevice


[.signature]
[subs="normal"]
----
client.removeWebAuthnDevice(<<authToken>>, <<deviceId>>, <<success>>, <<failure>>)
----

== About this command

When authenticated, the user can remove a registered device or passkey.

[NOTE]
====
* The WebAuthn feature must be enabled on your {company} account.
====
